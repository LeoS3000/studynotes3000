- generalized matrix 
- finite table of numerical values 
- indexed along several discrete dimensions
- 1d tensor: vector
	- sound sample
- 2d tensor: matrix 
	- grayscale image
- 3d tensor: vector of identically sized matrices 
	- multi-channel image
- 4d tensor: matrix of identically sized matrices 
	- sequence of multi-channel images

## uses
- encode signal to process
- encode internal state and parameters of neural network
## operations
- Transpose
- Concatenate
- Reorder views
- Narrow
- Expand
