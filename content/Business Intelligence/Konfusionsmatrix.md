
|                   | Ground Truth (+)    | Ground Truth (-)    |
| ----------------- | ------------------- | ------------------- |
| **Predicted (+)** | True Positive (TP)  | False Positive (FP) |
| **Predicted (-)** | False Negative (FN) | True Negative (TN)  |

- **Precision** = TP / (TP + FP)
- **Recall** = TP / (TP + FN)
- **Accuracy** = (TP + TN) / (TP + FP + TN + FN)
- **F₁ Score** $F₁ =\frac {2 * (Precision * Recall)} {(Precision + Recall)}$
